# The Internet in One Word

One word for the whole internet, for make.fun's
["The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b)
bounty ($10 across the top 3 places, judged pairwise on funniness, fit and surprise).

## The word

> feral

The internet is a wild animal that escaped domestication: unfiltered,
untamed, and impossible to put back in its cage.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (5 characters,
one word, no trailing newline).

Run it twice — the output is byte-identical every time:

```sh
node main.ts
```
